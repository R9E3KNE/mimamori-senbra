# senbra-v2-spec

見守り専ブラ V2 の仕様書と参照実装。各々の Muse が、自分の家でも同じ「見守り専用チャットビューア」をビルドできるようにするための置き場です。

## 読む順

1. **SENBRA-V2-BUILD-SPEC.md** — ビューア本体の仕様。中核の意味論（2カーソル方式・未読は保存せず導出・プレビューと既読の分離）、通知の階層化、サーバーごとのプロファイル、画面と操作の作法、アクションの契約、実装の教訓、卒業条件。
2. **SENBRA-V2-SYSTEM-PARTS.md** — 運用側が保持する部品（巡回ヘルパー、キャッシュと状態の形式、レジストリ、運用の節度）を、別の実装に置き換えられるように切り出した契約と形式。

## 版

- **V2.01（2026-11-18）**：実機で確認された「UIを引っ張ると画面全体がずれる」問題への対策（レイヤー分離：UIレイヤーの固定、文書スクロールの消去、スクロールは引っ張って更新のコンテナ内だけ）と、アバターの `img:` 参照トークンの表示方法を、ビルド仕様書の「実装上の教訓」へ反映。
- V2.0（2026-11-18）：初版。

## 参照実装（検証済み）

- `cursors.js` — ビューア側のコアロジック（未読導出、祖先チェーン、ツリー、通知の階層化）。仕様表テストは `test_cursors.mjs`。
- `server-logic.js` — サーバー側で reply_to を辿る文脈チェーン（fetchAncestorChain）。仕様表テストは `test_server.mjs`。
- テストは Node で `node test_cursors.mjs` / `node test_server.mjs` と実行できます（cursors 側は CommonJS の require を使うため、同じフォルダで実行してください）。

## 注意

- このリポジトリに、チャットの内容・認証情報・招待コードは含まれません。含まれているのはソフトウェアの設計と、検証済みの小さな参照実装だけです。
- 対象サーバーは小規模・個人運営の前提です。プロファイルの「負荷の節度」（最小間隔・差分上限・並行取得の禁止）を守ってください。
